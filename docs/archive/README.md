# CHLOM Institutional Archive

**Effective:** 2026-08-26  
**Governing source:** CrownThrive OS Phase 3 archive/version policy

CHLOM preserves historical material rather than silently rewriting or deleting institutional lineage.

## Archive precedence

CrownThrive OS determines institution-wide current/historical state. Within CHLOM's component scope, active registries, effective contracts, current services, current certification records, and evidence govern over historical papers, superseded phase documents, older architecture generations, and recovered research material.

## Archive candidates

A CHLOM record belongs in the archive/historical layer when it is:

- a prior Phase 1/2/2.5 or pre-Phase 3 status record;
- superseded by a current CHLOM contract, schema, registry, or architecture record;
- a prior provider/runtime certification version retained for evidence;
- a historical white paper, research artifact, roadmap, terminology generation, or recovered Help Center record;
- deprecated implementation guidance whose body remains evidence-worthy;
- a renamed, merged, split, or retired identity.

## Required dispositions

Use `HISTORICAL`, `SUPERSEDED`, `DEPRECATED`, `RETIRED`, or `UNRESOLVED_HISTORY`. Where known, record the successor/current file, effective period, disposition reason, and whether any requirements remain inherited.

Historical records must not be rewritten to look current. If the original body is important evidence, preserve it and add metadata, a wrapper, or a successor link.

## Contract versions

A v1/v2 contract is not stale merely because CrownThrive OS is in Phase 3. Contract/schema versions remain active until their own version lifecycle supersedes them. Archive by actual component status, not by numeral alone.

## Current canon

For current CHLOM orientation, start with the repository root `README.md`, active `registry/` records, `services/phase3-bounded-write/`, and CrownThrive OS current-state/version records.

PentaDocs and websites are downstream projections and do not control CHLOM archive disposition.
