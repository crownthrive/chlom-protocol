# CHLOM Current Baseline — Phase 2

## Current decision
CHLOM is rebuilt first as a practical rights, licensing, evidence, governance, settlement and remedies platform. Phase 2 creates the governed source and machine-readable contract needed for Phase 3 implementation.

## What is current
- Six-function model: Rights, Rules, Roles, Revenue, Records, Remedies.
- Cloud/API/event architecture.
- DAIL logical ledger.
- Dynamic Licensing Asset object model.
- Human approval gates.
- Private-by-default evidence.
- Append-only corrections and version history.
- Public-safe schemas and registries.

## What is not claimed current
- Dedicated CHLOM mainnet.
- Public CHLOM token economy.
- DAO-controlled production governance.
- Production ZK compliance orchestration.
- Public decentralized LEX.
- Autonomous legal or regulatory authority.
- Deployed oracle/slashing network.
- Cross-chain settlement bridge.

Historical research for these capabilities remains retained and queryable.
