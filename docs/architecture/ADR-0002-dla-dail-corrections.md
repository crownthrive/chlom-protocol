# ADR-0002 — DLA, DAIL and Legacy DAL/DLA Reconciliation

**Status:** Accepted for Phase 2
**Date:** 2026-08-17

## Decisions
- DLA means **Dynamic Licensing Asset**.
- DAIL means **Decentralized Autonomous Information Ledger**.
- Historical Decentralized Licensing Authority duties become Licensing Stewardship / Issuer Authority.
- Historical DAL duties are separated among DAIL, Case Management, Identity/Attestations, and Revenue Allocation.

This prevents an object, an authority, a ledger and a dispute function from sharing ambiguous acronyms.
