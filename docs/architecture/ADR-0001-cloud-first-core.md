# ADR-0001 — Cloud-First Human-Governed Core

**Status:** Accepted for Phase 2
**Date:** 2026-08-17

## Decision
Build the first operational CHLOM core as cloud-first, API-first, event-driven, multi-tenant and human-governed. Blockchain anchoring, ZK, smart-contract settlement, tokens, validators and DAO governance are optional later extensions.

## Rationale
The recovery corpus contains sophisticated decentralized designs but does not establish that all required legal, security, privacy, economic and operational prerequisites are production-ready. The six-function core creates useful institutional value now while preserving extension points.
