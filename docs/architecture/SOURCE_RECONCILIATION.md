# Source Reconciliation

## Governing precedence
1. Law, court/regulatory requirements, signed agreements and counsel-approved positions.
2. Explicit current founder directives and approved governance decisions.
3. Current ADRs.
4. Current product, architecture, data, security and operations baseline.
5. Current institutional handbooks and corridor manuals.
6. Verified production evidence.
7. Current public positioning, subject to proof standards.
8. Historical prospectuses and whitepapers.
9. Proposals, pitches and experimental studies.

## Resolved naming
- CHLOM = Compliance Hybrid Licensing and Ownership Model.
- DLA = Dynamic Licensing Asset.
- DAIL = Decentralized Autonomous Information Ledger.
- Legacy Decentralized Licensing Authority = Licensing Stewardship / Issuer Authority.

## Unresolved / ADR-required
- Token names and token roles across CHM, CHLOM Coin, C-CHLOM and L-CHLOM.
- Whether any later settlement layer should use a dedicated Substrate chain, EVM contracts, another network or no tokenized public layer.
- Exact legal characterization of tokenized licenses and governance assets.

No code or public statement may silently choose among those options.
