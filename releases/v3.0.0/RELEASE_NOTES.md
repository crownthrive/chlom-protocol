# CHLOM V3.0.0 — Phase 3 Governed Protocol

**Release date:** 2026-08-26  
**Institutional generation:** Phase 3

## Summary

CHLOM V3.0.0 formalizes the repository's Phase 3 institutional generation on top of the current mainline without regressing newer PENTA, PentaBooks, PentaFramework, PentaGreen, or runtime state. Existing component versions and historical evidence remain governed by their own lifecycle.

## Current operating picture

CrownThrive OS is the institution-wide source of truth. CHLOM remains authoritative for its exact protocol, governance, evidence, certification, registry, and component scope.

Phase 3 bounded-write certification remains operation-level and fail-closed. A verified operation never creates provider-wide mutation authority, and incomplete provider lanes remain held until evidence satisfies their governing contracts.

## Governance and repository hardening

This release formalizes:

- comprehensive proprietary CHLOM repository license and machine-use notice;
- archive/supersession policy;
- security and support policies;
- community/contribution conduct;
- contribution requirements;
- trademark/certification and PentaGreen naming notice;
- third-party notice policy;
- governed release publication with post-publication readback.

## Compatibility

`v3.0.0` is the repository generation, not an instruction to renumber every internal component. Existing v1/v2 schemas, contracts, services, APIs, and evidence records remain valid until their own version lifecycle supersedes them.

## Source-of-truth rule

CrownThrive OS governs CrownThrive-wide institutional state. CHLOM records govern their exact component scope. PentaDocs, websites, and other publication surfaces are downstream projections and do not redefine current OS/CHLOM state.

## Authority boundaries

- `HOLD` is not converted to `PASS` by release/version promotion.
- Provider capability is not CrownThrive provider-write authority.
- Operation-level certification does not grant provider-wide mutation authority.
- D3/new sovereign authority remains human-reserved unless separately changed by governing process.
- Historical records remain preserved and do not silently become current.

## Result

CHLOM now has a Phase 3 governance shell, archive model, rights-protection layer, and release lineage aligned with the current CrownThrive OS while preserving current mainline software and component-level semantic-version truth.
